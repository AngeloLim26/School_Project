# School Project Collection

A collection of school web development projects built using **HTML, CSS, and JavaScript**. This repository contains multiple activities and mini-projects created for learning and practicing front-end web development.

## 📂 Projects Included

### 1. Portfolio Website

A personal portfolio website showcasing:

* About Me page
* Skills page
* Hobbies page
* Contact page
* Responsive design

### 2. Mary Grace Coffee Website

A sample coffee shop website featuring:

* Menu page
* About Us page
* Product images
* Custom styling and navigation

### 3. Calculator

A simple calculator built with:

* HTML
* CSS
* JavaScript

Features:

* Basic arithmetic operations
* Interactive user interface
* Dynamic calculations

### 4. Registration Form (PT1)

A user registration form containing:

* Personal information fields
* Email validation
* Password confirmation
* Required input validation

### 5. Biodata Form (PT2)

A biodata collection form featuring:

* Personal information section
* Gender selection
* Date of birth input
* Form validation

### 6. Login Page

A simple login interface with:

* Custom styling
* JavaScript functionality
* Logo and image assets

## 🛠 Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)
